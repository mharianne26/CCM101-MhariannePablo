# Google Cloud Platform Research

## Brief Overview
Google Cloud Platform (GCP), commonly called Google Cloud, is Google's public cloud platform. It provides compute, storage, networking, databases, analytics, AI/ML, and container services.

## Global Infrastructure
Google Cloud uses a global infrastructure of regions and zones connected by Google's network. This supports distributed applications and services that need global reach.

## Cloud Management Console
The Google Cloud console is a browser-based interface for managing projects, services, resources, IAM, billing, monitoring, and other cloud capabilities.

## Four Core Services
1. **Compute Engine** – virtual machines and compute infrastructure.
2. **Cloud Storage** – object storage.
3. **Google Cloud VPC** – networking for cloud resources.
4. **Cloud IAM** – controls identities, roles, and permissions.

## Three Advantages
1. Strong AI and machine-learning ecosystem.
2. Strong Kubernetes and container technology.
3. High-performance global networking and data services.

## Typical Enterprise Use Cases
- AI and machine learning
- Data analytics
- Kubernetes applications
- Global web applications
- Research computing
- Cloud-native software development
