# Microsoft Azure Research

## Brief Overview
Microsoft Azure is Microsoft's public cloud platform. It provides infrastructure, platform, database, identity, analytics, AI, and application services.

## Global Infrastructure
Azure uses a worldwide network of regions and data-center infrastructure. Organizations can select appropriate regions to deploy workloads according to availability, performance, and compliance requirements.

## Cloud Management Console
The Azure portal is a browser-based management interface used to create, configure, monitor, and manage Azure resources.

## Four Core Services
1. **Azure Virtual Machines** – scalable virtual machines.
2. **Azure Blob Storage** – object storage for unstructured data.
3. **Azure Virtual Network** – private networking for Azure resources.
4. **Microsoft Entra ID** – identity and access management.

## Three Advantages
1. Strong integration with Microsoft products and enterprise environments.
2. Broad hybrid-cloud and enterprise management capabilities.
3. Large selection of compute, storage, database, security, and AI services.

## Typical Enterprise Use Cases
- Windows Server workloads
- Microsoft 365-connected environments
- Enterprise applications
- Hybrid cloud
- Identity and access management
- Data and AI solutions
