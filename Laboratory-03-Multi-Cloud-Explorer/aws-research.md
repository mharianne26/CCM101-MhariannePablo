# AWS Research

## Brief Overview
Amazon Web Services (AWS) is a major public cloud platform offering infrastructure and managed services for computing, storage, networking, databases, analytics, security, and application development.

## Global Infrastructure
AWS operates a global infrastructure organized into geographic Regions and Availability Zones, with additional edge and specialized infrastructure. This allows organizations to deploy applications closer to users and design for availability and resilience.

## Cloud Management Console
The AWS Management Console is a browser-based interface for creating, configuring, monitoring, and managing AWS resources and services.

## Four Core Services
1. **Amazon EC2** – provides scalable virtual computing capacity.
2. **Amazon S3** – provides object storage for data, files, backups, and application content.
3. **Amazon VPC** – provides logically isolated networking for AWS resources.
4. **AWS IAM** – manages identities, roles, permissions, and access to AWS resources.

## Three Advantages
1. Very broad service selection.
2. Mature global infrastructure and extensive ecosystem.
3. Large range of tools for scaling, automation, security, and enterprise workloads.

## Typical Enterprise Use Cases
- Web and mobile applications
- Enterprise application hosting
- Backup and disaster recovery
- Data analytics
- E-commerce platforms
- Container and Kubernetes workloads
